# 14 - FD2 Hackathon

In this assignment you will attempt to solve an issue in the live FarmData2 project and make a pull request to the that project.

## Requesting an Issue

Your instructor will direct you toward a set of issues in the [live FarmData2 repository](https://github.com/FarmData2/FarmData2) that have been created for this Hackathon.

1. Review the issues labeled "good first issue"
2. Find one that:
   a. You would like to work on.
   b. No one else has commented that they want to work on yet.
3. Have one team member comment on the issue.
4. Reload the issue page to ensure that you are the first to comment on the issue.
   - If someone commented before you, go back to step 2.
5. When you are the first to comment on an issue your instructor will assign it to you and it is yours to work on.

## Doing the Work

Once you have been assigned an issue:

1. Work in your development environment for "FarmData2-School".
2. Synchronize your `development` branch with the upstream repository.
2. Create a new feature branch from `development` for your work.
3. Break the work described in the issue up into sub-tasks.
4. Stage and commit your changes to your feature branch as you finish each sub-task.
5. Rebuild the example page and test it frequently.

## Submitting your Pull Request

When the example page works as required by the issue you

1. Push your feature branch to the `origin`.
2. Visit the origin repository on GitHub and open a pull request making sure that the: 
   - **base repository:** is set to the upstream **FarmData2/FarmData2** repository
   - **base:** is the **`development`** branch.
   - **compare:** is the feature branch with your changes.
3. Complete the Pull Request template in detail.
4. Create the Pull Request.
5. Check that you created the PR correctly by finding it in the Pull Requests section of the [live FarmData2 repository](https://github.com/FarmData2/FarmData2).
6. Visit the "Files changed" tab and confirm that the changes that you made look correct.

## After you Submit your Pull Request

If it is within 1 hour of the end of the hackathon then you are finished and you may leave.

If there is more than 1 hour remaining:
1. Go back to the "Requesting an Issue" and select a "good second issue" to work on.
   - Be sure to create a new feature branch from `development` for your work on the new issue.
2. The instructor will review your pull request and:
   a. Mark it as "Accepted" and merge it if everything looks good.
   b. "Request changes" if there are issues to be addressed.
3. If changes are requested:
   a. Use `git stash` to save what you are currently working on.
   b. Switch to the feature branch for your PR.
   c. Make the requested changes.
   d. Stage and commit those changes to your feature branch.
   e. Push the feature branch to GitHub to update your PR.
   f. Visit your PR on GitHub and respond to each of the comments explaining how your update has addressed them.
   g. Switch back to the branch you were working on.
   h. Use `git stash pop` to retrieve the work you stashed.

## Want Something to Do Later?

The [FarmData2 Project](https://github.com/FarmData2) is open-source and accepts contributions, so you are free to continue contributing to this project and building your GitHub resume.  Feel free to continue working on any of the issues that were set aside for this hackathon or visit the full [FarmData2 Issue Tracker](https://github.com/FarmData2/FarmData2/issues) and find others issues that interest you. You can also reach out on the [FarmData2 Zulip Chat](https://farmdata2.zulipchat.com/) if you want to discuss issues or what types of contributions you might make to the project.
