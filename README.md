# FD2-School-Materials
This repository contains the materials for the FarmData2 (FD2) School classroom / onboarding materials.

FD2 School is a combination of an introduction to web development using Vue.js, practice in open source contribution, and an onboarding to the FarmData2 project. The FD2 School materials walk students through a series of exercises in which they learn basic HTML/CSS, Vue.js, Cypress testing and apply what they learn by adding a basic Harvest feature to FarmData2. The mechanisms used to submit work gives students practice with team based collaborative development and a forking/branching open source contribution workflow using git/GitHub.
