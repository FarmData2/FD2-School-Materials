# 13 - OSS3 - Project Work

This assignment continues the project work part of the course. In the project work you will work in pairs to address issues that have been posted in the issue tracker. Each of these issues addresses a bug or requests a new feature for the Harvest form on which you have been working.

## Continuing the Project Work

You work on the project should continue in three ways:
1. If your PR from the 12-OSS2 assignment does not yet fully resolve the issue you should continue working on that issue.
   - If you have not resolved the issue be sure to ask any necessary clarifying questions in the comments on the issue.
2. If you received a review of your PR from the 12-OSS2 assignment that requests changes to your PR, you should address the requested changes.
   - Make each of the requested changes.
   - Add a reply to each comment to the PR Review in GitHub explaining how you addressed the requested change.
3. If your PR from 12-OSS2 was approved, you should select another issue from the issue tracker to work on.
   - Use the same workflow as for the 12-OSS2 assignment and create a new PR for the new issue.

## Turing in Your Work

Your effort on OSS3 will be assessed by:
- The content of your draft pull request to the upstream. 
  - This PR should show progress toward a solution to the issue on which you are working.
  - This PR must contains at least one commit from each partner.
- Comments/Questions/Responses posted to the issue or draft pull request.
